# Changelog

## [0.1.0] - 2026-09-27

Initial release of webOTP-server, including:

- Zero-knowledge encrypted vault synchronization and optimistic concurrency.
- Encrypted vault history, retention, and revision restore.
- User registration, login, refresh-token rotation, and logout.
- Device registration, listing, and revocation.
- User profile and lock/theme preferences.
- Security audit logging with sensitive metadata redaction.
- Health checks and optional MSSQL persistence.
- Helmet, CORS, global throttling, sanitized errors, and request redaction.
- OpenAPI documentation and shared webOTP extension contract types.
